## Q10. What is spark.task.cpus and when must it be set greater than 1? What is the interaction with spark.executor.cores for resource allocation?

`spark.task.cpus` defaults to `1` and is documented simply as "Number of cores to allocate for each task"[^spark-configuration]. The number of concurrent task slots on an executor is derived jointly from it and `spark.executor.cores`: the Spark configuration reference notes, in the context of speculative-execution slot counting, that "the number of slots is computed based on the conf values of spark.executor.cores and spark.task.cpus minimum 1"[^spark-configuration]; i.e., slots per executor ≈ `spark.executor.cores / spark.task.cpus`. Raising `spark.task.cpus` above 1 therefore reduces the number of tasks an executor runs concurrently, reserving more cores per individual task.
