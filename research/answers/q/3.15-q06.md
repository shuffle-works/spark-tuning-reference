## Q6. What is the default and valid range for spark.sql.adaptive.advisoryPartitionSizeInBytes?

Default is 64MB, since version 3.0.0[^spark-sql-perf-tuning][^spark-configuration]. In the Spark SQL config source it's a `fallbackConf` pointing at the deprecated `spark.sql.adaptive.shuffle.targetPostShuffleInputSize`, version-tagged 3.0.0[^spark-source-sql-conf]; being a `bytesConf`, it accepts byte-size strings (e.g. `64MB`, `128m`)[^spark-configuration]. The retrieved source definition shows no explicit upper/lower bound (`checkValue`) beyond a positive byte size. [NEEDS-REVIEW] for a hard documented range beyond "must be a valid byte-size string."
